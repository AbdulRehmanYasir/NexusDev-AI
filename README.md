# NexusDev AI

NexusDev AI is an autonomous engineering and DevOps platform built with React, TypeScript, Express, and a local deterministic engineering analysis engine.

## Features

- Autonomous engineering workflow
- Repository and workspace analysis
- Incident investigation and remediation
- Deployment monitoring
- CI/CD pipeline troubleshooting
- Pull request review and merge workflows
- Role-based access control
- Audit logging
- Engineering reasoning and recommendations
- Local analysis with no external AI API dependency

## Tech Stack

- React
- TypeScript
- Vite
- Express
- Node.js
- Tailwind CSS
- npm

## Run Locally

Install dependencies:

    npm install

Create your environment file:

    Copy-Item .env.example .env

Set a unique administrator password in .env with at least 12 characters.

Start the development server:

    npm run dev

## Production Build

Build the application:

    npm run build

Start the production server:

    npm start

    npm start

## Cost

NexusDev AI does not require a paid AI provider or external AI API key. Its engineering analysis and workflow responses use local deterministic logic.

## Security

Never commit your .env file or real credentials. Only .env.example should be committed.
